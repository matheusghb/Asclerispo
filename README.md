# Asclerispo 🩺

## Saúde e Bem-Estar Comunitário

O Asclerispo é uma aplicação web desenvolvida com o propósito de aproximar a população de profissionais da saúde por meio de uma plataforma de perguntas e respostas. Inspirado nos fóruns de discussão tradicionais, o projeto propõe uma experiência moderna e acessível, permitindo que cidadãos esclareçam dúvidas relacionadas à saúde com o auxílio de médicos voluntários.

A iniciativa busca combater a desinformação, incentivar a conscientização sobre saúde preventiva e ampliar o acesso a orientações confiáveis.

## Problema

O acesso à informação confiável sobre saúde representa um desafio para muitas pessoas. A dificuldade de identificar sintomas, a falta de conhecimento sobre determinadas doenças e a ausência de orientação adequada podem contribuir para atrasos na busca por atendimento médico.

Além disso, a utilização de mecanismos de busca e ferramentas de inteligência artificial como fontes de orientação médica pode resultar em informações imprecisas, levando os usuários a interpretações equivocadas sobre sua saúde.

Diante desse cenário, torna-se necessário desenvolver uma plataforma que facilite o acesso a informações confiáveis e promova uma comunicação mais acessível entre a população e profissionais da saúde.

## Objetivo

Desenvolver uma aplicação web que funcione como uma comunidade digital de saúde, conectando cidadãos a médicos voluntários para o esclarecimento de dúvidas que não necessitem de uma consulta médica completa.

O projeto tem como objetivos:

- Facilitar o acesso a informações confiáveis sobre saúde.
- Promover a saúde preventiva e a conscientização da população.
- Combater a desinformação relacionada a questões médicas.
- Incentivar a interação entre cidadãos e profissionais da saúde.
- Oferecer um ambiente organizado para publicação e consulta de perguntas e respostas.

## Funcionalidades

### Funcionalidades principais

- **Feed de perguntas e respostas:** Exibição de publicações realizadas pelos usuários, permitindo o compartilhamento de dúvidas relacionadas à saúde.
- **Respostas verificadas:** Identificação de respostas fornecidas por profissionais da saúde cadastrados e verificados na plataforma.
- **Sistema de tags:** Organização das publicações por categorias, como sintomas, pediatria, dieta, ansiedade e prevenção.
- **Filtros de publicações:** Possibilidade de visualizar conteúdos recentes, publicações da semana e do mês.
- **Favoritos:** Permitir que os usuários salvem publicações de interesse para consulta posterior.
- **Perfil de usuário:** Exibição das informações e publicações dos participantes da comunidade.
- **Perfil de profissionais:** Apresentação das especialidades e informações dos médicos participantes.

### Funcionalidades complementares

- **Campanhas de prevenção:** Divulgação de campanhas públicas de vacinação e conscientização sobre saúde.
- **Conteúdo educativo:** Disponibilização de informações sobre prevenção de doenças, primeiros socorros e hábitos saudáveis.
- **Busca de publicações:** Pesquisa de perguntas e respostas por palavras-chave ou categorias.

## Tecnologias

O desenvolvimento da aplicação utiliza as seguintes tecnologias e ferramentas:

- **React:** Biblioteca JavaScript utilizada para o desenvolvimento da interface de usuário, permitindo a criação de componentes reutilizáveis e interfaces dinâmicas.
- **Vite:** Ferramenta de desenvolvimento utilizada para a ambientação do projeto React, oferecendo inicialização rápida do ambiente, servidor de desenvolvimento e suporte à construção da aplicação.
- **HTML5:** Estruturação dos elementos da aplicação.
- **CSS3:** Estilização da interface e desenvolvimento de layouts responsivos.
- **JavaScript:** Linguagem utilizada para implementar funcionalidades interativas e a lógica da aplicação.
- **Node.js e npm:** Ambiente e gerenciador de pacotes utilizados para instalar as dependências e executar os scripts de desenvolvimento.
- **Git:** Controle de versão do código-fonte.
- **GitHub:** Hospedagem do repositório e colaboração entre os integrantes da equipe.

## Instruções de execução

### Pré-requisitos

Para executar o projeto, é necessário possuir:

- [Node.js](https://nodejs.org/) instalado.
- npm, instalado junto ao Node.js.
- [Visual Studio Code](https://code.visualstudio.com/) (recomendado).
- Git instalado.

### Executando o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/ravendc12/Asclerispo.git
   ```

2. Abra o projeto no Visual Studio Code.

3. Abra o terminal integrado do VS Code.

4. Acesse a pasta da aplicação:

   ```bash
   cd asclerispo-app
   ```

5. Instale as dependências definidas no arquivo `package.json`:

   ```bash
   npm install
   ```

6. Execute o projeto utilizando o Vite:

   ```bash
   npm run dev
   ```

7. O terminal exibirá o endereço local da aplicação. Acesse o endereço indicado pelo Vite no navegador, geralmente:

   ```text
   http://localhost:5173
   ```

A aplicação estará disponível para utilização no ambiente de desenvolvimento.
